# Visual Craft

## Layout Systems

- Choose the layout type before styling: editorial, transactional, dashboard, documentation, marketing, or mobile task flow.
- Use grids to create rhythm, not cages. Break the grid intentionally only to emphasize priority.
- Dense screens need alignment, grouping, and progressive disclosure more than decoration.
- Landing pages should tell a story: promise, proof, details, action.

## Typography and Content

- Typography is hierarchy, measure, line height, weight, contrast, and rhythm—not just font choice.
- Keep line lengths readable and test long translations or dynamic content.
- Pair strong headings with calm body text; avoid making everything bold, large, or gradient.
- Content clarity is UX. Replace vague hype with specific user value.

## Motion

- Motion must serve feedback, orientation, continuity, or emphasis.
- Define entrance/exit, duration, easing, interrupt behavior, and reduced-motion fallback.
- Animate transform/opacity when possible; avoid expensive effects that hurt performance.
- Do not animate critical flows in ways that hide state or delay action.

## Data Visualization

- Pick chart type by question: comparison, trend, distribution, relationship, or part-to-whole.
- Every chart needs title/context, labels, units, scale clarity, legend when needed, and accessible color choices.
- Use annotations for thresholds/anomalies; do not make users decode everything from color.
- Provide table/summary alternatives for critical data when possible.

## Design Critique Rubric

Review using:

1. Purpose: does the screen make the user goal easier?
2. Hierarchy: is the most important thing obvious?
3. Legibility: can users scan and read comfortably?
4. Interaction: are states and flows clear?
5. Accessibility: keyboard, focus, contrast, motion, semantics.
6. Distinctiveness: does it avoid generic AI patterns for a product-specific reason?
7. Maintainability: does it fit the existing system and code conventions?
