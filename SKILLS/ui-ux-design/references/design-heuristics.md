# UI/UX Design Heuristics

## Direction Before Pixels

Before designing, decide:

- Audience: who uses this and under what pressure?
- Job: what action should become easier?
- Tone: institutional, playful, premium, technical, editorial, calm, urgent, etc.
- Memory hook: what will make the interface recognizable without hurting usability?
- Constraints: brand, accessibility, data density, device, localization, performance, existing components.

## Hierarchy

- Make the primary action visually obvious.
- Use spacing and grouping before adding borders everywhere.
- Prefer clear scan paths over symmetrical decoration.
- Keep dense dashboards legible through alignment, rhythm, and progressive disclosure.
- Do not let secondary cards, badges, or gradients compete with the main task.

## Typography

- Use type to create hierarchy, not just size changes.
- Avoid default font choices unless the product/design system requires them.
- Limit font families; vary weight, size, tracking, and line height intentionally.
- Large headings need tighter line height; body text needs breathing room.

## Color and Surfaces

- Start from semantic roles: background, surface, primary, accent, success, warning, danger, muted.
- Use color to guide action and meaning, not to decorate every element.
- Verify contrast in text, icons, borders, badges, and disabled states.
- Gradients, blur, glass, noise, and shadows must support depth or mood; otherwise remove them.

## Motion and Interaction

- Motion should clarify state changes or add controlled delight.
- Respect reduced-motion preferences.
- Keep hover effects subtle and touch-safe; hover is not a mobile interaction model.
- Focus states must be visible and consistent.

## UX Basics

- Design loading, empty, error, disabled, success, and partial-data states.
- Forms need labels, help text, validation timing, error recovery, and keyboard flow.
- Dashboards need prioritization: critical metrics first, details progressively revealed.
- Navigation should answer: where am I, what can I do, where can I go next?
